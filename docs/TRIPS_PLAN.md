# เรื่องเล่าทริป (Trip stories)

เจ้าของอนุมัติ 26 พ.ย. 2569 หลังลองแบบร่าง ทุกการออกไปเล่าเป็นเรื่องได้ ไม่ว่าจะเป็นทริปต่างประเทศ ทริปในไทย หรือบ่ายวันอาทิตย์ เรื่องเล่นเต็มจอเป็นบทๆ: ปก → เส้นทาง → บทของแต่ละวันและรูปในวันนั้น → หน้าจบที่รวมทุกโมเมนต์เป็นภาพเล็ก พร้อมสรุปตัวเลข

**การทดสอบจริงครั้งแรก:** เจ้าของไปจีน → ฮ่องกง → จีน วันที่ 4–13 ธ.ค. 2569 ฟีเจอร์นี้จึงต้องขึ้นเว็บจริงก่อน 4 ธ.ค.

วิธีสร้างทริปทีละขั้นสำหรับผู้ทดสอบ: [TRIPS_GUIDE.md](TRIPS_GUIDE.md)

## สิ่งที่เจ้าของตัดสินแล้ว
- ค่าเริ่มต้นคือ **ทุกคนเห็น** (ขึ้นฟีดและให้ค้นหาเจอ) เปลี่ยนเป็นผู้ติดตามหรือเฉพาะฉันได้
- ใช้ได้ **ระหว่างทริป**: วันไหนอยู่ในช่วงทริป หน้าโพสต์โมเมนต์จะมีสวิตช์ "เพิ่มเข้าทริป" เปิดไว้ให้ และ **หลังทริป**: เลือกรูปจากเครื่องได้ทีละหลายรูป
- **ทริปย่อยตามเมือง** (เจ้าของ 26 พ.ย.) เช่น ไปจีน 10 วัน แบ่งเป็น กว่างโจว 4–6, เซินเจิ้น 7–9, ฮ่องกง 10–13 ธ.ค. ผู้เขียนตั้งเองไม่กี่บรรทัด แล้วรูปทุกรูปเข้าเมืองตามวันที่ถ่ายเอง ไม่ต้องมีพิกัด รูปที่มีพิกัดใช้เสนอช่วงให้ ("ตามเมืองในรูป") แต่ละทริปย่อยเล่นแยกและแชร์แยกได้ (`?leg=`)
- **สร้างทริปที่ My Hub** (เจ้าของ 26 พ.ย.) ส่วน "ทริปของฉัน" แสดงทริปที่กำลังไป ทริปที่จะไป และร่าง ส่วนโปรไฟล์แสดงแค่ทริปที่เผยแพร่แล้ว
- หน้าจบรวมทุกโมเมนต์เป็นภาพเล็ก (เจ้าของ 26 พ.ย.) ถ้ามีเกิน 30 รูป จะเลือกรูปกระจายให้ทั่วทั้งทริป แตะรูปไหนก็กระโดดไปรูปนั้น

## ระบบทำงานอย่างไร
- **ข้อมูล:** migration `0069_trips.sql` เพิ่มตาราง `app.trips` `app.trip_items` และ `app.geo_places` ระบบนี้ใช้ Postgres เท่านั้น ในโหมดไม่มีฐานข้อมูล ทริปจะปิดไว้
- **เวลา:** เก็บเป็นเวลาตามนาฬิกาของที่ที่ถ่าย (`taken_local`) ไม่แปลงเขตเวลา ทริปจึงแบ่งวันตามวันของที่นั่น
  - รูปจากเครื่อง: อ่านเวลาจาก EXIF ในเบราว์เซอร์ก่อนย่อรูป (`lib/media/exif.ts`) ถ้าไม่มีจะใช้วันที่ของไฟล์แทน
  - โพสต์ระหว่างทริป: ใช้เวลาของเครื่องตอนโพสต์
- **สถานที่:** เก็บเฉพาะระดับเมือง พิกัดถูกปัดเหลือทศนิยม 2 ตำแหน่ง (ประมาณ 1 กม.) ไม่เก็บจุดที่ถ่ายจริง
  - ชื่อเมืองหาจาก OpenStreetMap Nominatim (`lib/trips/geo.ts`) ส่งแค่จุดที่ปัดแล้ว ไม่มีข้อมูลสมาชิกติดไปด้วย และเก็บผลไว้ใช้ร่วมกันใน `app.geo_places`
  - Nominatim ให้ถามได้วินาทีละครั้ง หน้าแก้ไขจึงเรียกถามซ้ำจนครบ
  - iPhone มักตัดพิกัดออกตอนเลือกรูปในเบราว์เซอร์ ทริปย่อยที่ผู้เขียนตั้งจึงสำคัญกว่าพิกัดเสมอ วันที่อยู่นอกทริปย่อยและไม่มีพิกัด จะใช้เมืองของวันที่ใกล้ที่สุด
- **เรื่องเล่า:** `lib/trips/story.ts` (ใช้ร่วมกันทั้งเซิร์ฟเวอร์และเบราว์เซอร์)
  - ลำดับ: ทริปใหญ่ → ทริปย่อย (`tripParts`) → วัน (`tripChapters`) → โมเมนต์
  - ทริปย่อย: ของที่ผู้เขียนตั้ง ส่วนวันที่อยู่นอกทุกทริปย่อย ระบบจัดกลุ่มเองตามเมืองในรูป
  - เส้นทาง: หนึ่งจุดต่อทริปย่อย ถ้ากลับไปเมืองเดิมหลังออกไปแล้วจะนับเป็นอีกจุด (จีน → ฮ่องกง → จีน จึงได้ 3 จุด) วางตามพิกัดเฉลี่ยของรูป ถ้าไม่มีพิกัดจะเรียงตามลำดับแทน
  - ตัวเล่น: ปก → เส้นทาง → หน้าเปิดทริปย่อย → หน้าเปิดวัน (เมื่อทริปย่อยมีหลายวัน) → รูป → หน้าจบ
- **หน้า**
  - `/trips/new` สร้างทริป
  - `/trips/[id]/edit` เพิ่มรูป ตั้งชื่อเมืองรายวัน เลือกปก ซ่อนหรือลบรูป และเผยแพร่
  - `/trips/[id]` หน้าสาธารณะที่ render บนเซิร์ฟเวอร์ มี JSON-LD `TouristTrip` ส่วน `?play=1` เปิดตัวเล่นทันที
- **ทางเข้า:** My Hub ส่วน "ทริปของฉัน" (`components/myhub/MyTrips.tsx`), แท็บ "ทริป" ในโปรไฟล์ (เฉพาะทริปที่เผยแพร่แล้ว) และแถว "เรื่องเล่าทริปจากเพื่อนๆ" ในฟีดหน้าแรกหลังโพสต์ที่ 6 ส่วนเมนู ＋ ยังไม่ได้เพิ่ม เพราะเพิ่งจัดใหม่ใน BE-483

1. ปุ่ม "ไปตามรอยทริปนี้": สร้างแผน "ไปกัน" ตามเส้นทางของทริป
2. การ์ดและคลิปสรุป 9:16 สำหรับแชร์ลง IG Story และ LINE
3. เพิ่มคลิปจากเครื่องในหน้าแก้ไข (ตอนนี้คลิปเข้าทริปได้เฉพาะจากโพสต์ระหว่างทริป)
4. หน้าประเทศและเมืองที่สร้างจากทริปของสมาชิก เช่น `/trips/japan/kyoto` และเพิ่มทริปเข้า sitemap
5. แผนที่โลกบนโปรไฟล์ (ประเทศและเมืองที่เคยไป)
6. ทีมงานซ่อนทริปได้จากหน้า admin (มี `setTripModeration` แล้ว แต่ยังไม่มีหน้าจอ) และสมาชิกรายงานทริปได้
