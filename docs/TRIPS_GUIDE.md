# วิธีสร้างทริปและเรื่องเล่า (สำหรับ Gemini)

คู่มือนี้บอกขั้นตอนสร้างทริปและเล่าเรื่องผ่านหน้าเว็บ ตั้งแต่สร้างทริปจนเผยแพร่ ถ้าอยากรู้ว่าระบบทำงานยังไง ดู [TRIPS_PLAN.md](TRIPS_PLAN.md) ส่วนรูปแบบการรายงานปัญหาอยู่ใน [TEST_REPORTS.md](TEST_REPORTS.md)

## ก่อนเริ่ม

- **ใช้ได้ที่ไหน:** ฟีเจอร์นี้อยู่ใน `origin/claude` ตั้งแต่ BE-484 (26 พ.ย. 2569) ให้ merge `origin/claude` เข้า `tester` ก่อน ตามขั้นตอนปกติ เว็บจริงจะใช้ได้หลังเจ้าของ merge เข้า `main` และรัน migration 0069 แล้วเท่านั้น
- **ทดสอบที่ไหน:** ใช้ `npm run dev` ซึ่งต่อกับฐานข้อมูล dev (รัน 0069 บน dev ไว้แล้ว) **ห้ามสร้างทริปทดสอบบนเว็บจริง** เจ้าของจะสร้างทริปจริงของเจ้าของเอง
- **บัญชีที่ใช้:** ต้องเป็นสมาชิกที่ล็อกอินแล้ว ยืนยันอีเมลแล้ว และรับคำมั่นของคอมมูนิตี้แล้ว คือบัญชีที่โพสต์โมเมนต์ได้ บัญชีใหม่จะสร้างทริปไม่ได้ และจะเห็นข้อความบอกว่าต้องทำอะไรก่อน
- **รูปที่ใช้:** ใช้ไฟล์ JPEG ที่มี EXIF (เวลาถ่ายและพิกัด) จะเห็นระบบทำงานครบที่สุด รูปที่ไม่มี EXIF ใช้ได้เหมือนกัน แต่ระบบจะใช้วันที่ของไฟล์แทน ส่วนไฟล์ HEIC อัปโหลดใน Chrome ไม่ได้

## 1. สร้างทริป

1. เปิด **มายฮับ** (`/myhub`) ดูส่วน **ทริปของฉัน** แล้วกด **เล่าทริปใหม่** หรือเปิด `/trips/new` ตรงๆ ก็ได้
2. ใส่ **ชื่อทริป** (2–80 ตัวอักษร) เช่น "จีน–ฮ่องกง 10 วันกับแก๊งเดิม"
3. เลือก **วันเริ่ม** และ **วันกลับ** (ยาวได้ไม่เกิน 61 วัน)
4. เลือกว่า **ใครเห็นทริปนี้:** ทุกคน (ค่าเริ่มต้น) ผู้ติดตาม หรือเฉพาะฉัน
5. กด **สร้างทริป แล้วเลือกรูป** ระบบจะพาไปหน้าแก้ไข ตอนนี้ทริปยังเป็นร่าง ยังไม่มีใครเห็น

## 2. ใส่รูป

1. ในหน้าแก้ไข กด **เพิ่มรูปจากเครื่อง** เลือกได้ทีละหลายรูป และเลือกทั้งทริปทีเดียวก็ได้
2. ระบบจะอ่านเวลาและพิกัดจากรูป ย่อรูป แล้วอัปโหลด ปุ่มจะแสดง "กำลังเพิ่มรูป 12/40"
3. อัปโหลดเสร็จแล้ว ระบบจะหาชื่อเมืองจากพิกัด ใต้ปุ่มจะขึ้น "กำลังหาชื่อเมืองจากรูป…" ประมาณ 1 วินาทีต่อหนึ่งเมือง
4. รูปจะเรียงตามเวลาที่ถ่าย และแบ่งเป็นวัน เช่น วันที่ 1, วันที่ 2 …

**ขีดจำกัด:** ทริปหนึ่งมีได้ 300 รูป อัปโหลดได้ 320 รูปต่อชั่วโมงต่อสมาชิก ตอนนี้เพิ่มได้เฉพาะรูป คลิปเข้าทริปได้ทางเดียว คือโพสต์โมเมนต์ระหว่างทริป (ข้อ 6)

## 3. แบ่งทริปย่อยตามเมือง

ถ้าไปหลายเมือง ให้แบ่งเป็นทริปย่อย เช่น กว่างโจว 4–6, เซินเจิ้น 7–9, ฮ่องกง 10–13 ธ.ค.

1. อัปโหลดครั้งแรก ถ้ารูปมีพิกัดตั้งแต่ 2 เมือง ระบบแบ่งทริปย่อยให้เอง (ขึ้นข้อความ "แบ่งเป็น N ทริปย่อยตามเมืองในรูปแล้ว")
2. ส่วน **ทริปย่อยตามเมือง** อยู่ใต้รูปทั้งหมด แก้ชื่อเมือง วัน หรือใส่ **ประโยคเดียวของเมืองนี้** ได้ ระบบบันทึกเองเมื่อแตะออกจากช่อง (ขึ้นว่า "บันทึกแล้ว") ไม่มีปุ่มบันทึกแล้ว
3. **ตั้งตามเมืองในรูป** ใช้ตั้งใหม่จากรูป ส่วน **เพิ่มทริปย่อย** ใช้เพิ่มเอง
4. รูปทุกรูปจะเข้าทริปย่อยตามวันที่ถ่ายเอง ไม่ต้องมีพิกัด

**กติกา:** ทริปย่อยต้องอยู่ในช่วงวันของทริป วันห้ามซ้อนกัน (ระบบจะขึ้นว่า "A กับ B วันซ้อนกัน") และมีได้ไม่เกิน 20 ช่วง

## 4. แต่งเรื่อง

แตะรูปในหน้าแก้ไข จะเปิดแผงแก้รูป ซึ่งมี:
- **คำบรรยายในเรื่อง** (ไม่เกิน 300 ตัวอักษร) แล้วกดบันทึก
- **ตั้งเป็นปก** รูปปกใช้เป็นหน้าแรกของเรื่องและการ์ดในฟีด
- **ซ่อนจากเรื่อง** รูปยังอยู่ในทริป แต่ไม่โชว์ในเรื่อง
- **ลบรูปนี้** (ถ้ารูปมาจากโมเมนต์ ปุ่มจะเป็น "เอาออกจากทริป" และโมเมนต์ยังอยู่)

**เล่าทีละรูป** เปิดรูปทีละรูปพร้อมช่องคำบรรยาย กด **บันทึก แล้วรูปถัดไป** หรือ **ข้าม** ไปเรื่อยๆ

**ใส่เพลงประกอบเรื่อง** เลือกเพลงจากคลังเดียวกับคลิป เพลงจะเล่นในตัวเล่นเรื่อง (ปุ่มลำโพงมุมบนปิดเพลงได้)

ชื่อทริป คำเกริ่น วัน และใครเห็นได้ อยู่ใน **แก้รายละเอียด** ใต้ชื่อทริป ระบบบันทึกให้เองเมื่อแตะออกจากช่อง

## 5. ดูเรื่องและเผยแพร่

1. กด **ดูเรื่อง** เพื่อดูตัวอย่างเต็มจอ ลำดับคือ ปก → เส้นทาง → หน้าเปิดทริปย่อย → หน้าเปิดวัน (ถ้าทริปย่อยนั้นมีหลายวัน) → รูป → หน้าจบที่รวมทุกรูป
2. **วิธีใช้ตัวเล่น:** แตะขวาเพื่อไปต่อ แตะซ้ายเพื่อย้อน กดค้างเพื่อหยุด บนคอมใช้ ← → Space Esc ได้ ในหน้าจบ แตะรูปไหนจะกระโดดไปรูปนั้น
3. กด **เผยแพร่** หรือ **เผยแพร่เลย** ที่หน้าจบของตัวอย่าง (ต้องมีรูปที่ไม่ได้ซ่อนอย่างน้อย 1 รูป) ระบบพาไปหน้าทริปและเปิดหน้าต่าง **เผยแพร่ทริปแล้ว**: รูปลงสตอรี่ IG (รูปแนวตั้ง 9:16), ส่งทาง LINE, แชร์ผ่านแอปอื่น, คัดลอกลิงก์
4. ในหน้าทริป แต่ละทริปย่อยมีปุ่ม **เล่นเฉพาะ{เมือง}** และ **แชร์ทริปย่อยนี้** ลิงก์ที่แชร์เป็น `/trips/[id]?leg=...`
5. ทริปที่เผยแพร่และให้ทุกคนเห็น จะขึ้นในแท็บ **ทริป** ของโปรไฟล์ และแถว **เรื่องเล่าทริปจากเพื่อนๆ** ในฟีดหน้าแรก (หลังโพสต์ที่ 4 ทริปของคนที่ติดตามขึ้นก่อน)
6. คนอื่นส่งหัวใจและคอมเมนต์ในหน้าทริปได้ เจ้าของได้แจ้งเตือน ท้ายหน้ามี **อยากไปแบบนี้บ้าง** (ไปตามรอย และถ้าเป็นเมืองในไทยมีลิงก์ที่เที่ยวและตั้งตี้)

## 6. ไปตามรอยทริปของคนอื่น

เปิดทริปของคนอื่นที่เผยแพร่แล้ว แล้วกด **ไปตามรอย** หรือกด **ไปตามรอยทริปนี้** ที่หน้าจบของเรื่อง เลือกวันที่จะเริ่มเดินทาง ระบบจะแสดงทริปย่อยตามวันที่เราเลือก กด **สร้างทริปของฉัน** แล้วจะได้ทริปร่างของเราเอง ขึ้นใน My Hub และหน้าทริปจะบอกว่าตามรอยมาจากทริปไหน ถ้าเปิดจากลิงก์ทริปย่อย (`?leg=`) หรือเล่นเฉพาะทริปย่อยแล้วกดที่หน้าจบ จะได้ทริปเฉพาะเมืองนั้น ทริปตัวเองตามรอยไม่ได้ และถ้ากดซ้ำจะได้ทริปเดิม ทริปที่ตามรอยมา ระหว่างเป็นร่าง หน้าแก้ไขจะแสดงแผนของทริปต้นทางทีละเมือง และปุ่ม **ชวนเพื่อนไปด้วยทาง LINE**

## 7. เล่าระหว่างทริป

วันไหนอยู่ในช่วงวันของทริป หน้าโพสต์โมเมนต์จะมีสวิตช์ **เพิ่มเข้าทริป** เปิดไว้ให้ โพสต์แล้วรูปหรือคลิปจะเข้าทริปพร้อมเวลาของเครื่องและเมืองที่อยู่ ตอนโพสต์เบราว์เซอร์จะขอสิทธิ์ตำแหน่ง ถ้าไม่ให้ รูปยังเข้าทริปได้ แต่จะไม่มีเมือง

ถ้าจะทดสอบข้อนี้ ให้สร้างทริปที่ช่วงวันครอบวันนี้ก่อน

## เคล็ดลับให้เรื่องน่าดู

- **เลือกปกเอง:** ใช้รูปที่บอกทั้งทริปได้ในรูปเดียว ถ้าไม่เลือก ระบบจะใช้รูปแรก
- **ไปหลายเมือง ให้แบ่งทริปย่อยเสมอ:** เส้นทางจะชัด และชื่อเมืองเป็นชื่อที่เราตั้งเอง
- **วันละ 5–15 รูปพอ:** รูปที่ซ้ำกันให้ซ่อน ตัวเล่นเปิดรูปละประมาณ 5 วินาที
- **คำบรรยายสั้น 1–2 บรรทัด:** เล่าความรู้สึกหรือเรื่องเล็กๆ ไม่ต้องบอกชื่อที่ เพราะชื่อเมืองขึ้นให้อยู่แล้ว
- **คำเกริ่นทริป 1 บรรทัด:** จะขึ้นในหน้าปกของเรื่อง

## สิ่งที่ควรเช็กแล้วรายงานเป็น TR-###

- เวลาที่ขึ้นในเรื่องตรงกับเวลาถ่ายในรูปไหม (ต้องไม่เลื่อนไปตามเขตเวลา)
- ชื่อเมืองสมเหตุสมผลไหม (ระดับเมือง ไม่ใช่ระดับเขต)
- ทริปย่อย วันซ้อน และวันนอกช่วงทริป ระบบกันไว้ได้ถูกต้องไหม
- ตัวเล่นทุกเฟรมบนมือถือ 390px และบนคอม (ข้อความไม่ถูกตัด ปุ่มกดได้)
- ทริปแบบผู้ติดตามและเฉพาะฉัน คนอื่นต้องเปิดไม่ได้ (404) และร่างต้องไม่มีใครเห็น
- ลิงก์ `?leg=` เปิดเฉพาะทริปย่อยนั้น
- ระหว่างอัปโหลด รูปขึ้นทันทีพร้อมวงกลมโหลด และรูปที่เสร็จทยอยเข้าทริป
- หัวใจและคอมเมนต์ (ใช้สองบัญชี) ลบคอมเมนต์ได้ทั้งคนเขียนและเจ้าของทริป
- รูปลงสตอรี่: ข้อความไทยครบ ไม่ถูกตัด (ในเบราว์เซอร์คอมจะบันทึกเป็นไฟล์)
- ไปตามรอย: วันของทริปย่อยเลื่อนถูก ตัวเลข "N คนไปตามรอยแล้ว" ขึ้นที่ทริปต้นทาง (ใช้สองบัญชี)

## หลังทดสอบ

ลบทริปทดสอบทุกครั้ง ที่หน้าแก้ไข เลื่อนลงล่างสุด กด **ลบทริปนี้** แล้วกด **ลบทริป** ระบบจะลบรูปที่อัปโหลดให้ด้วย ส่วนโมเมนต์ที่โพสต์ระหว่างทดสอบ ให้ลบจากตัวโมเมนต์เอง ทริปที่สร้างจากการไปตามรอยก็ต้องลบด้วย
