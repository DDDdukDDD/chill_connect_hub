เขียนใหม่และเทียบกับโค้ดเมื่อ 2026-11-03 เรียงตามลำดับที่ควรเดิน เสร็จข้อไหนให้ลบออก (ประวัติอยู่ใน Git) เลื่อนงานใดเพิ่มให้เติมที่นี่

**ใครทำ:** `เจ้าของ` = ต้องใช้บัญชี เงิน หรือการตัดสินใจของเจ้าของ · `Claude` = ทำในโค้ดได้เลย · `ร่วม` = เจ้าของตัดสินใจหรือเปิดบัญชี แล้ว Claude ทำต่อ

- [ ] `เจ้าของ` ดู Vercel > Observability > Data Cache ว่ามี hit จริง ข้อนี้ยืนยันว่า cache ข้ามเซิร์ฟเวอร์ทำงาน (จากภายนอกยืนยันได้แค่ว่าโค้ดขึ้นแล้ว)
- [ ] `เจ้าของ` ตัดสินใจจากตัวเลขด้านบน: อยู่ต่อ, ย้ายเว็บจริงไป org `Chillwaa` หรืออัปเกรด Pro
- [ ] `เจ้าของ` ตั้ง `DATABASE_URL` เฉพาะ environment Preview ให้ชี้ฐานพัฒนา แล้ว redeploy (ยังไม่รู้ว่า preview ต่อฐานไหน)

- [ ] `เจ้าของ` **สำรองข้อมูล** เปิด Point-in-Time Recovery (แผนเสียเงิน) แล้วลองกู้หนึ่งครั้ง
- [ ] `ร่วม` **รูปและคลิปบน Blob** ทดสอบการลบบนเว็บจริง และดูค่าใช้จ่ายทั้ง Blob และโควตาย่อรูปของ Vercel (อัปโหลดและแสดงผลใช้งานจริงแล้ว ตรวจ 3 พ.ย.)
- [ ] `ร่วม` **สถานที่ใกล้ตัวและการค้นหาตอนปักหมุด** Overpass ฟรีตอบว่าเต็มทุกครั้งที่ทดสอบ และ Nominatim จำกัดราว 1 ครั้งต่อวินาที เลือกบริการเสียเงินหรือตั้งเอง และตรวจเงื่อนไข เพราะข้อมูล Google Places เก็บไว้กับโพสต์ไม่ได้
